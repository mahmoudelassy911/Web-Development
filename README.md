# Portfolio-WebDev

Lab work for **CSE343 Web Development** (Ain Shams University, Faculty of Engineering).

**Student:** Mahmoud Abdelhamid El Assy (24P0333), G2/S3

Each lab is in its own folder.

| Lab | Folder | Topic | What it is |
| --- | --- | --- | --- |
| Lab 2 | [`Lab2-Portfolio`](Lab2-Portfolio) | HTML & CSS | A personal portfolio page |
| Lab 3 | [`Lab3-Greet-Goodbye`](Lab3-Greet-Goodbye) | JavaScript & the DOM | Type a name to greet it and add it to a list; click a name to say goodbye and remove it |
| Lab 4 | [`Lab4-Todo-App`](Lab4-Todo-App) | Advanced JavaScript & TypeScript | A to-do app with filters, editing and an "items left" counter |
| Lab 5 | [`Lab5-React`](Lab5-React) | Intro to React | Task 1: a movie watch list. Task 2: a comments section |

## How to run each lab

- **Lab 2 and Lab 3:** open the `.html` file in your browser.
- **Lab 4:** open `index.html` in your browser. To rebuild `app.js` from `app.ts`, run `npm install` and then `npx tsc` in the folder. See the lab's own [README](Lab4-Todo-App/README.md).
- **Lab 5:** the quick way is to open `Lab5.html` in your browser (it loads React from the internet, so no install is needed). To run the full React project, run `npm install` and then `npm start` in the folder.
